About Hello South Korea

Hello South Korea is a small, free site for people who are learning about Korea, visiting, or living there. It has five tools and a short guide to go with each.

How the tools work

  • Korean name generator: picks from a fixed list of names, based on what you type. The same input gives the same result. If a listed name starts with a similar sound to yours, it is shown first.
  • Name in Hangul: looks your name up in a built-in list. If it is not there, it guesses from the spelling and tells you that the result is approximate.
  • Age calculator: shows international age, year age and traditional age for any date.
  • Skincare routine builder: puts the products you select into a common order.
  • Size converter: shows approximate conversions from a reference table.

Limits

Results are for reference only. This is not legal, medical or professional naming advice. For legal matters, check official sources. Before you buy clothes or shoes, check the brand's own size chart.

Your input

The tools run in your browser. The names and dates you type are not sent to us. See the Privacy Policy.
